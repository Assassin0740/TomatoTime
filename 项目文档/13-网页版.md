# 13 · 网页版（`web/`，v2 复刻桌面版界面）

> **文档性质**：网页版的功能范围、实现方案、数据存储策略与部署方式。
> 版本历史：v1（2026-09-30）为独立设计的 PWA 界面，与桌面版观感不一致，已废弃；
> **v2（2026-09-30）= 复刻桌面版界面**：直接复用桌面版 `计时器.html + style.css + renderer.js`，
> 由 `bridge.js` 在浏览器里模拟主进程。下文描述的均为 v2。
> 相关代码：`web/index.html`、`web/style.css`、`web/renderer.js`、`web/bridge.js`、`web/sw.js`、`web/overrides.css`

---

## 1. v2 核心方案：垫片复用，而不是重写

桌面版三层：`计时器.html`（结构）+ `style.css`（样式）+ `renderer.js`（逻辑），
原本靠 Electron 主进程（main.js）承担计时权威、图片落盘、提醒轮询等职责。

网页版把 main.js 的职责在浏览器里重实现了一遍（`bridge.js`），renderer.js **一行不改**：

| renderer.js 里的调用 | bridge.js 的模拟 |
|---|---|
| `isElectron` 判定 | 垫 `window.require` + `window.process` → 判定为 true，走与桌面版相同代码路径 |
| `ipcRenderer.send/invoke` | 按通道名分发到浏览器实现（见下表） |
| 计时器权威 | 100ms 漂移补偿状态机，`timer-end`/`timer-status` 广播、自动开始下一阶段、保存默认时长，与 main.js 逐行对齐 |
| 任务图片 `save-note-image` | base64/网络图存 **IndexedDB**，内容里仍写 `NoteImages/img_xxx.png` 相对路径（桌面版同一约定），由 sw.js 拦截 fetch 从 IndexedDB 出图——renderer 的图片代码含 GC 正则零改动 |
| 背景图 `get-background-images` | 内置清单（web/Draws/ 22 张 webp）+ 用户自定义（IndexedDB） |
| 设置 `main-settings:get/set` | 存 localStorage 键 `webMainSettings` |
| 任务提醒 | 30s 轮询 localStorage 的 notes（同 main.js 的 24h 窗口与 `id:remindAt` 去重键），系统通知 + 页内提示 |
| 剪贴板 | `navigator.clipboard` 读写位图（`clipboard:write-image` 的 file 模式降级） |
| 悬浮窗 / 全局快捷键 / AI 接口 / 表格同步 | 桌面版专属，send 安全空转、invoke 返回禁用态；相关设置栏由 overrides.css 隐藏 |

任务数据与桌面版**同在 localStorage 的 `notes` / `archived_notes` 键**，导出 JSON 两边互通。

## 2. 目录结构与运行

```
web/
├── index.html              # = 桌面版 计时器.html（改标题、加 manifest/overrides、加 bridge.js 引用）
├── style.css               # = 桌面版 style.css 原样（改样式去桌面版改、两边同步拷）
├── renderer.js             # = 桌面版 renderer.js 原样
├── bridge.js               # ★ 网页版主进程垫片（唯一的新逻辑）
├── overrides.css           # 隐藏桌面版专属面板（悬浮窗/AI/表格同步）与按钮
├── sw.js                   # 应用壳预缓存 + NoteImages 从 IndexedDB 出图 + 大图运行时缓存
├── manifest.webmanifest    # PWA 清单
├── icon.svg                # 图标
├── Draws/                  # 背景图（webp，与桌面版 Draws/ 同步拷贝）
├── 表情包/                 # 表情包（与桌面版同步拷贝）
├── 仕事終わったよ.wav       # 计时结束音
└── 休憩終わったよ.wav       # 计时结束音
```

本地起服务（浏览器要求 `http(s)` 才能用 Service Worker）：

```bash
python -m http.server 8899 --directory web
```

## 3. 数据存哪里（与 v1 相同的重点）

| 数据 | 存储位置 | 说明 |
|---|---|---|
| 任务、评论、提醒 | **localStorage**（键 `notes` / `archived_notes`，与桌面版同键名） | 导出 JSON 与桌面版互通 |
| 任务图片 | **IndexedDB**（库 `timer-web`，表 `images`） | 内容里是 `NoteImages/` 相对路径，SW 出图 |
| 自定义背景 | **IndexedDB**（表 `custombg`） | |
| 设置 | **localStorage**（界面设置各键 + `webMainSettings`） | |

三条限制（v1 遗留，仍成立）：
1. 清空浏览数据 / 换浏览器 / 隐私模式会丢——「导出全部数据（JSON）」和持久化申请照旧可用；
2. 一个域名一份数据；
3. 桌面版导出里的图片是 `file://` 引用，浏览器加载不出（文字与结构不受影响）；反之网页版的 `NoteImages/` 图片在桌面版也是裂图。

## 4. 功能范围（v2）

| 模块 | 状态 |
|---|---|
| 界面 | 与桌面版 100% 一致（同一份 HTML/CSS/renderer） |
| 计时 | 工作/休息、开始/暂停/保存默认/切换、自动开始下一阶段、到点音效、系统通知 |
| 任务 | 与桌面版一致：优先级/类型/提醒、卡片与表格双视图、评论、Ctrl+V 贴图、图片入库、搜索筛选排序归档、表情包 |
| 已隐藏（桌面版专属） | 悬浮窗、全局快捷键、AI 本地接口、企业微表格同步（浏览器跨域做不到） |

## 5. 部署到服务器

纯静态，`web/` 目录交给 Nginx 即可：

```nginx
location /timer/ {
    alias /var/www/timer-web/;
    try_files $uri $uri/ /timer/index.html;
    # Service Worker 必须每次校验，否则用户一直用旧壳
    location = /timer/sw.js { add_header Cache-Control "no-cache"; }
}
```

- **HTTPS 必须**（Service Worker / 通知 / 持久化存储在纯 HTTP 下被禁用）；
- **改了 renderer.js / style.css / index.html 必须同步改 `web/` 里的副本并把 `sw.js` 的 `CACHE_VERSION` 加一**；
- 同步资源：改 `Draws/` 或 `表情包/` 后要把新文件拷进 `web/`，若新增背景图还需更新 `bridge.js` 顶部的 `DEFAULT_BGS` 清单。
