# 13 · 网页版（`web/`）

> **文档性质**：网页版的功能范围、数据存储策略、部署方式与和桌面版的差异。
> 创建日期：2026-09-30 ｜ 对应目录：`web/` ｜ 相关代码：`web/index.html`、`web/app.js`、`web/style.css`、`web/sw.js`

---

## 1. 为什么做网页版

桌面版（Electron）功能最全，但只能装在 Windows 上、要下载安装包。网页版解决三件事：

1. **零安装**：给个网址就能用，手机/平板/别人电脑都行；
2. **复用同一套界面思路**：设置面板同样是「分栏（Tab）」结构，改一处两边都好对；
3. **数据仍然只在用户自己电脑/手机上**：不联网、不上传、不做任何统计。

> 它**不是**桌面版的替代品：全局快捷键、悬浮窗、AI 本地接口（`127.0.0.1:17890`）、
> 企业微信表格同步这些能力是桌面版独有的（浏览器沙箱做不到）。

## 2. 目录结构与运行

```
web/
├── index.html              # 单页结构：计时器 + 任务列表 + 设置分栏面板
├── style.css               # 深色/浅色双主题、响应式、表格视图日期规则
├── app.js                  # 全部逻辑：IndexedDB 存储 / 计时器 / 任务 CRUD / 设置 / 导入导出
├── manifest.webmanifest    # PWA：可"安装"到桌面或手机主屏
├── sw.js                   # Service Worker：只缓存应用壳，断网也能打开
└── icon.svg                # 应用图标
```

本地起服务（浏览器要求 `http(s)` 才能用 Service Worker，直接双击 `index.html` 会用不了 PWA）：

```bash
# 任选其一，在仓库根目录执行
python -m http.server 8899 --directory web
npx serve web
```

然后访问 `http://127.0.0.1:8899/`。

## 3. 数据存在哪里（重点）

| 数据 | 存储位置 | 说明 |
|---|---|---|
| 任务、评论、提醒 | **IndexedDB**（库名 `timer-web` → 表 `tasks`） | 容量按浏览器配额（通常几百 MB～几 GB） |
| 图片 | **IndexedDB**（表 `images`，存 Blob） | 不塞 base64，避免把存储撑爆；渲染时转 objectURL |
| 设置 | **localStorage**（键 `timerweb:settings`） | 小、同步、够用 |

### 三条必须知道的限制

1. **清空浏览数据 / 换浏览器 / 隐私模式都会丢**。所以设置里有：
   - 「导出全部数据（JSON）」——任务 + 图片（转 dataURL）+ 设置，一个自包含文件；
   - 「申请持久化存储」——`navigator.storage.persist()`，能显著降低被浏览器自动清理的概率，
     但**不是永久保证**（用户手动清理照样会没）。
2. **一个域名一份数据**：`a.com` 和 `b.com` 互不相通，正式上线要早定域名。
3. **网页不能往用户磁盘任意路径写文件**：导出只能走"下载"，想直接写文件夹需要用户授权
   （File System Access API），本期没做。

> 想要"绝对不丢"的本地存储，用桌面版（写 `%APPDATA%\计时器`）；
> 想要多设备同步，得配服务端或第三方表（桌面版已有的企业微信表格同步就是这条路）。

| 备份 | 导出 / 导入 JSON、清空数据、持久化申请、存储占用统计 | 自动定时备份 |

### 与桌面版的数据互通

- 网页版导出的 JSON：`{ app, version, settings, tasks, images }`，可以再导回网页版；
- **桌面版导出的 JSON 也能导进网页版**（识别 `storage.notes` / `storage.archived_notes`），
  但桌面版里的图片是 `file://` 引用，浏览器出于安全限制**加载不出来** —— 文字与结构不受影响。

## 5. 界面上两条"踩过坑"的规则（两版共用）

1. **表格视图的日期列**：日期与时间各自 `white-space: nowrap`，**只在两者之间换行**。
   否则 `2026-09-30 18:45:31` 会被浏览器从连字符处拆成 `2026-09-` / `30` / `18:45:31`。
2. **任务内容列不写死宽度**：只给 `min-width`（网页版 200px），剩下交给列宽；
   真挤不下时让表格横向滚动，而不是把每一列一起压扁。

## 6. 部署到服务器

纯静态，把 `web/` 整个目录丢给 Nginx/Apache 即可，例如：

```nginx
location /timer/ {
    alias /var/www/timer-web/;
    try_files $uri $uri/ /timer/index.html;
    # Service Worker 必须每次校验，否则用户一直用旧壳
    location = /timer/sw.js { add_header Cache-Control "no-cache"; }
}
```

注意事项：

- **HTTPS 是必须的**（除了 `localhost`）：`Notification`、`Service Worker`、
  `navigator.storage.persist()` 在纯 HTTP 下多数浏览器直接禁用；
- 改了前端 JS/CSS，记得把 `web/sw.js` 里的 `CACHE_VERSION` 加一，否则老用户还在用缓存；
- 不需要任何后端，服务器挂了也不影响已打开页面的使用（数据在本机）。
