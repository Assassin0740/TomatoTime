## 三、文档维护约定

1. **单一事实来源**：本目录是项目文档的唯一权威版本，代码改动后应同步更新相关文档。
2. **变更留痕**：任何范围 / 架构级的改动，先在 `07-变更管理记录.md` 登记 CR，再实施。
3. **风险闭环**：`06` 中的风险项如实际发生，需从"风险"转为"问题"并标注实际影响。
4. **进度同步**：每完成一个可交付成果，在 `05` 中更新里程碑状态。
5. **文档与代码的对应关系**：涉及文件路径的地方均使用仓库相对路径（如 `main.js`、`float.html`），便于代码定位。
