# 专注计时器 · 终极置顶悬浮版

一款基于 Electron 开发的专注计时器应用：计时、任务管理、图片粘贴、悬浮窗，
并且可以**被 AI 直接调用**、把任务**自动同步到企业微信智能表格**。

## ✨ 功能特性

### 🕐 计时功能
- 工作时间/休息时间切换，时间可自定义
- 倒计时结束提醒（声音 + 弹窗）
- 暂停/继续、一键重置
- 全局快捷键控制（无需切回窗口）

### 📝 任务管理
- 添加、编辑、删除任务；优先级（高/中/低）与类型（短期/长期）
- 完成状态切换与自动归档（按日期分组的归档历史）
- 任务评论、图片附件
- 卡片视图 / 表格视图，拖拽排序、批量操作
- **全局搜索**：内容与评论一起搜，卡片、表格、归档三处同步过滤
- **任务提醒**：给任务设置提醒时间，到点弹系统通知（过期超 24 小时不再补发）

### 🖼️ 图片支持
- 任务中可直接粘贴图片（Ctrl+V / 右键「粘贴图片」）
- **与微信双向互通**：微信截图可粘进来，应用里的图片也能复制到微信
- 图片落盘到 `NoteImages/`，按 SHA-256 去重，不再把 base64 塞进数据文件

### 🤖 AI 接入 · 本地 API + CLI
- 本机 HTTP 接口，AI 助手 / 脚本可以直接注入任务与图片、查询与修改任务、控制计时器
- 默认关闭、仅监听 `127.0.0.1`、带令牌校验；接口自描述 `GET /api/schema`
- **命令行工具**（类似 Unity 的 CLI）：`node timer-cli.js add "写周报" -p high`，端口/令牌自动发现，零依赖
  - Node 版 `timer-cli.js` / Python 版 `timer-cli.py` / 快捷方式 `timer.cmd`
- 详见 [`项目文档/10-AI接入API.md`](项目文档/10-AI接入API.md)、[`项目文档/12-命令行CLI.md`](项目文档/12-命令行CLI.md)

### 🔗 WebHook · 同步到表格
- 任务变化（新增/完成/修改/归档/删除）自动推送到企业微信**智能表格**
- 支持按字段 ID 映射、按列类型格式化（文本/单选/复选框/日期/图片）
- 同样支持推给自建服务、企业微信群机器人（records / flat / text / 自定义模板）
- 详见 [`项目文档/11-WebHook同步表格.md`](项目文档/11-WebHook同步表格.md)

### 🌊 悬浮窗
- 置顶显示倒计时，可锁定位置
- 可显示当前任务与图片缩略图

### ⚙️ 个性化设置
- 背景明暗、音量、字体大小（完整/纯净模式）
- 发光效果（开关/颜色/强度）、呼吸效果
- 自定义背景图片、纯净模式
- 开机自启、全局快捷键开关


## 📖 使用说明

### 基本操作
1. **开始/暂停计时**：点击「开始」按钮，或按 `Ctrl+Alt+Space`
2. **切换工作/休息**：点击「切换」按钮，或按 `Ctrl+Alt+M`
3. **修改时间**：点击分钟或秒钟数字，输入新值后点「保存」

### 添加与管理任务
1. 在输入框输入任务内容，选优先级与类型，点「添加」或按 Enter
2. 卡片上可完成、编辑、删除；右键还能设置提醒、推送到表格
3. 顶部工具面板里可以搜索、排序、筛选、切换视图、批量操作

### 粘贴图片（与微信互通）
- 应用里：`Ctrl+V` 或右键 →「粘贴图片」（微信、截图工具复制的位图都支持）
- 复制出去：图片上右键 →「复制图片」；粘贴到微信不成功时改用「复制为文件（微信兼容）」

### AI 注入任务
1. 设置面板 →「🤖 AI 接入 · 系统集成」→ 打开「AI 接口」
2. 点「复制调用示例（给 AI / 脚本）」把示例和令牌一起给 AI
3. AI 就能把任务（含图片）直接写进你的任务列表

### 同步到智能表格
1. 在企业微信智能表格里建好列，创建「接收外部数据」的 WebHook，复制地址
2. 设置面板 →「🔗 WebHook · 同步到表格」→ 粘贴地址、打开「启用同步」
3. 把该页面里的**示例 JSON** 粘到「解析字段」，核对自动匹配好的列对应关系，点「保存」
4. 点「发送测试」，表格里出现一条测试记录即配置成功

## 📁 项目结构

```
计时器/
├── 计时器.html            # 主界面
├── main.js                # Electron 主进程（窗口/托盘/快捷键/剪贴板/提醒/WebHook 触发）
├── api-server.js          # 本地 AI 接入 API（HTTP 路由与参数校验）
├── webhook.js             # 推送外部表格（智能表格字段映射、差分事件、重试）
├── timer-cli.js           # 命令行工具（Node 版，给 AI / 脚本用）
├── timer-cli.py           # 命令行工具（Python 版，功能相同）
├── timer.cmd              # CLI 快捷方式
├── store.js               # 数据落盘 + localStorage 镜像
├── preload.js             # 渲染进程桥接
├── renderer.js            # 界面逻辑
├── style.css              # 样式
├── tests/                 # node --test 测试
├── 项目文档/               # 需求、设计、路线图与使用文档
├── Draws/ 表情包/ 图标/     # 资源
└── 仕事終わったよ.wav 等    # 提示音
```

## 🔧 配置说明

| 存放位置 | 内容 |
|---|---|
| `localStorage`（渲染进程） | 计时设置、显示设置、任务数据 |
| `<userData>/main-settings.json` | AI 接口开关/端口/令牌、开机自启、全局快捷键、提醒开关、WebHook 配置 |
| `<userData>/NoteImages/` | 任务图片（SHA-256 命名，自动去重） |
| `<userData>/floatWindowConfig.json` | 悬浮窗配置 |

## 📝 快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl+Alt+Space` | 开始 / 暂停计时 |
| `Ctrl+Alt+M` | 切换工作 / 休息 |
| `Ctrl+Alt+F` | 开关悬浮窗 |
| `Ctrl+Alt+N` | 唤起窗口并聚焦任务输入框 |
| `Enter` | 添加任务（输入框中） |
| `Ctrl+V` | 粘贴图片 / 文本（输入框中按纯文本粘贴） |
